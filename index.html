Part 1 of 3

Install the tools

Showing steps for

You'll use Terminal and Homebrew. About 10 to 15 minutes, mostly waiting.

OpenCode 2 doesn't run directly on Windows, so you'll install WSL, a Linux terminal built into Windows. About 15 to 20 minutes, including a restart. If you get stuck, see Microsoft's WSL guide.

  1. Open Terminal

    Press Cmd + Space, type Terminal and press Enter.

    To run a command from this page: click Copy, click in Terminal, press Cmd + V to paste, then press Enter.

  2. Install Homebrew

    Terminal
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    It asks for your Mac password. Your password won't show as you type, which is normal. It may also install Apple's Command Line Tools (this includes Git) and can take 5 to 10 minutes.

    When it finishes, it prints Next steps with a few commands. Copy and run those. On most Macs they look like this:

    Terminal
    echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

    You should see brew --version prints a version number.

  3. Install OpenCode, Node.js and GitHub CLI in one go

    Terminal
    brew install opencode node gh
    Tip

    Homebrew's opencode is OpenCode 2, the version we use in the session.

  4. Close Terminal and open it again

    Quit Terminal fully (Cmd + Q) and reopen it, so it picks up the new tools.

  5. Install VS Code

    Download VS Code for Mac from code.visualstudio.com/download, open the download and drag Visual Studio Code into your Applications folder. (Homebrew users can run brew install --cask visual-studio-code instead.)

  6. Check everything installed

    Terminal
    opencode --version
node --version
gh --version
git --version

    You should see a version number for each. Node should be v22.20 or higher.

  7. Open PowerShell as administrator

    Press the Windows key, type PowerShell, right-click it and choose Run as administrator. Click Yes if Windows asks for permission.

    The next command is short, so it's easiest to type it in.

  8. Install WSL

    PowerShell
    wsl --install

    When it finishes, restart your laptop.

    Tip

    If it prints a help page instead, WSL is already there. Run wsl --install -d Ubuntu instead.

  9. Open Ubuntu in Windows Terminal

    After the restart, press the Windows key, type Terminal and open Terminal. Click the small ⌄ arrow next to the tab and choose Ubuntu.

    The first time, it asks you to create a username and password. Your password won't show as you type, which is normal.

    No Terminal app? Some Windows 10 laptops don't have it. Install Windows Terminal from the Microsoft Store first.

    Heads up

    From here on, run every command in the Ubuntu tab in Terminal. Don't use the Ubuntu window that opens by itself after the restart, or PowerShell: paste often doesn't work there.

    Tip

    How to paste: click Copy on this page, click in the Ubuntu tab and press Ctrl + V (or right-click). Then press Enter.

    You should see a prompt ending in :~$. If it shows /mnt/c/... instead, type cd ~ and press Enter.

  10. Install OpenCode 2

    Terminal
    curl -fsSL https://opencode.ai/v2/install | bash

    When it says Successfully added opencode to $PATH, run this so Ubuntu picks it up:

    Terminal
    exec $SHELL

    You should see opencode --version prints a version number.

  11. Install Node.js with nvm

    nvm is a small tool that installs Node.js inside Ubuntu (nvm on GitHub).

    Terminal
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash

    Reload Ubuntu so it finds nvm, then install Node.js:

    Terminal
    exec $SHELL
nvm install --lts

  12. Install GitHub CLI

    This is the official command from GitHub CLI for Ubuntu. Copy the whole block in one go and paste it with Ctrl + V. It asks for your Ubuntu password.

    Terminal
    (type -p wget >/dev/null || (sudo apt update && sudo apt install wget -y)) \
	&& sudo mkdir -p -m 755 /etc/apt/keyrings \
	&& out=$(mktemp) && wget -nv -O$out https://cli.github.com/packages/githubcli-archive-keyring.gpg \
	&& cat $out | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null \
	&& sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg \
	&& sudo mkdir -p -m 755 /etc/apt/sources.list.d \
	&& echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null \
	&& sudo apt update \
	&& sudo apt install gh -y
    Tip

    Windows may warn that you're pasting text with multiple lines. That's expected here: click Paste anyway, then press Enter if it doesn't start by itself.

  13. Install VS Code and its WSL extension

    Install VS Code on Windows from code.visualstudio.com/download. Keep the option Add to PATH ticked.

    Open VS Code, click the Extensions icon on the left (four squares), search for WSL and install the one by Microsoft (WSL extension). Then close VS Code.

    Close Ubuntu and open it again, so it can find the code command.

  14. Check everything installed

    Terminal
    opencode --version
node --version
gh --version
git --version

    You should see a version number for each (Git comes with Ubuntu). Node should be v22.20 or higher.

Part 2 of 3

GitHub and Vercel

These accounts let OpenCode push your code and let you put your site live in the session. Run commands in Ubuntu.Run commands in Terminal.

  1. Create a GitHub account

    Sign up at github.com/signup if you don't have one. As a student you can also apply for the free GitHub Student Developer Pack.

  2. Create a Vercel account

    Go to vercel.com/signup, choose the free Hobby plan, then Continue with GitHub so the two accounts are linked.

  3. Tell Git who you are

    Use your name and the same email as your GitHub account.

    Terminal
    git config --global user.name "Your Name"
git config --global user.email "you@example.com"

  4. Sign in to GitHub from the terminal

    Terminal
    gh auth login

    Use the arrow keys and Enter to choose:

    1. GitHub.com
    2. HTTPS
    3. Yes to authenticate Git with your GitHub credentials
    4. Login with a web browser

    Copy the one-time code it shows and press Enter. Paste the code into the browser page that opens and click Authorize.

    On Windows the browser might not open from Ubuntu. If so, open https://github.com/login/device in your normal browser and paste the code there.

  5. Check you're signed in

    Terminal
    gh auth status

    You should see Logged in to github.com with your username.

Part 3 of 3

Create your project

The last part: a starter Next.js site that we'll turn into your portfolio in the session.

  1. Create your project

    In your terminal (the Ubuntu tabTerminal), run this. It downloads everything the site needs, so it can take a few minutes.

    Terminal
    cd ~
npx create-next-app@latest my-portfolio --yes

    If it asks Ok to proceed? (y), type y and press Enter.

  2. Open your project in VS Code

    Your project lives inside Ubuntu at ~/my-portfolio, not in your Windows Documents or Desktop. That's on purpose: it's much faster and live reload works. Open it from the Ubuntu tab:

    Terminal
    cd ~/my-portfolio
code .

    The first time, VS Code takes a minute to set itself up inside Ubuntu.

    You should see VS Code opens with your files on the left and WSL: Ubuntu in the bottom-left corner.

    Heads up

    Don't open the project from Windows by browsing to \\wsl.localhost\Ubuntu\.... VS Code warns about an unknown host and the terminal and Git won't work properly. Always use code . from Ubuntu.

    Open VS Code, choose File then Open Folder, and pick my-portfolio in your home folder.

    You should see your project's files listed on the left.

    If VS Code asks whether you trust the authors of the files, click Yes, I trust the authors (or Trust). It's your own project. Without this, VS Code opens in Restricted Mode and some features are switched off.

  3. Open a terminal inside VS Code

    From the menu bar choose Terminal then New Terminal (shortcut Ctrl + `). A terminal opens at the bottom of VS Code, already in your project folder.

    You should see a prompt ending in ~/my-portfolio$, and WSL: Ubuntu still in the bottom-left corner.a prompt in your my-portfolio folder.

    Tip

    From here on, run every command in VS Code's terminal. You can open more terminals with the + button on the terminal panel.

  4. Start your site

    Terminal
    npm run dev

    Open localhost:3000 in your browser.

    You should see the Next.js starter page. Click back in the terminal and press Ctrl + C to stop it.

  5. Check OpenCode and the free AI models

    In the same VS Code terminal, start OpenCode:

    Terminal
    opencode

    Type this and press Enter:

    Type this
    /models

    You should see models marked Free, such as GLM-5.3-Flash Free. Press Ctrl + C to exit.

    Tip

    No free models listed? Type /connect, choose OpenCode and sign in with a free account, then try /models again.

    On Wednesday you'll work in this one window: your files at the top, one terminal running your site and another running OpenCode.

Troubleshooting

If something goes wrong

The most common problems and their fixes. If none of these help, don't worry: come along and we'll fix it at the start.

Paste doesn't work, or ^V appears (Windows)

You're probably in the plain Ubuntu or PowerShell window, which has no tabs. Open the Terminal app and choose Ubuntu from the ⌄ arrow, then paste with Ctrl + V. Stuck in the plain window? Click the icon in its top-left corner, then Edit and Paste. A warning about multiple lines is normal: click Paste anyway.

opencode: command not found straight after installing

The install worked, but your terminal hasn't picked it up yet. Run exec $SHELL, or close the terminal and open a new one.

The prompt shows /mnt/c/WINDOWS/system32 (Windows)

You're in a Windows folder, not your Linux home. Type cd ~ and press Enter. Better still, use the Ubuntu tab in Terminal, which starts in the right place.

command not found after installing something

Run exec $SHELL, or close your terminal completely and open a new one. New tools are only picked up by a fresh terminal. On a Mac, check you ran the Homebrew Next steps commands.

nvm: command not found (Windows)

Run exec $SHELL after installing nvm, then nvm install --lts.

wsl --install fails or mentions virtualisation (Windows)

Virtualisation may be switched off on your laptop. Follow Microsoft WSL troubleshooting, or skip it and a helper will help you on the day.

OpenCode install complains about unzip (Windows)

Run sudo apt install unzip -y in Ubuntu, then run the OpenCode install command again.

Node is older than v22.20

Mac: brew upgrade node. Windows: nvm install --lts then nvm alias default 'lts/*'. Then reopen your terminal.

The browser doesn't open for gh auth login

Open https://github.com/login/device yourself and paste the one-time code from the terminal.

gh auth status says you're not logged in

Run gh auth login again and choose HTTPS, then Yes to authenticate Git.

VS Code says the host wsl.localhost isn't allowed (Windows)

That happens when you open the project from Windows by its \\wsl.localhost path. Click Cancel, install the WSL extension in VS Code, then in Ubuntu run cd ~/my-portfolio and code .. The bottom-left corner should say WSL: Ubuntu.

I can't find my project in Documents or on my Desktop (Windows)

It's inside Ubuntu at ~/my-portfolio, on purpose. Open it with code . from Ubuntu, or run explorer.exe . to see it in File Explorer (it appears under Linux in the sidebar).

VS Code says I'm in Restricted Mode

Click Manage in the blue banner at the top (or the Restricted Mode label in the bottom-left corner), then Trust. It's your own project, so it's safe to trust.

code: command not found in Ubuntu (Windows)

Close Ubuntu and open it again after installing VS Code. If it still fails, reinstall VS Code on Windows with Add to PATH ticked.

Port 3000 is already in use

Next.js will pick another port, such as 3001. Open the address it prints in the terminal.

No free models in /models

Inside OpenCode, type /connect, choose OpenCode and sign in with a free account. Then try /models again.

I've got a Chromebook or a tablet

These won't run the tools. Come along and pair with someone, or borrow a laptop if you can.
